## №10 Отбой и подъём
- Для привычки в часах (сон) в `HabitEntry` добавляются `startTime String?` и `endTime String?` («01:30», «08:00»). `value` = длительность в минутах, считается из них с переходом через полночь. Ночь относится к дате подъёма.
- **Ввод:** `HoursSheet` получает режим «Лёг / Встал» — два колеса времени (`WheelPicker` уже есть). Длительность видна сразу. Старый ввод «часы» остаётся запасным.
- **Режим:**
  - на странице сна — средний отбой и подъём за 14 дней и разброс отбоя («режим сбит: отбой гуляет ±1,5 ч»);
  - график показывает полосы «отбой → подъём» по ночам (горизонтальные бары по оси 20:00–12:00) вместо высоты столбика;
  - цель отбоя — опционально в настройках привычки.
- Бот (утренний брифинг) спрашивает «Во сколько лёг и встал?» кнопками-пресетами по твоему обычному режиму и отдельно «другое время» → мини-приложение.

## Этап 2. Hermes как главный интерфейс
- **Контракт агента** (`services/nutrition/textLog.ts` → общий `services/assistant.ts`):

  ```
  { food: [...], weight?: {kg}, sleep?: {bed?: 'HH:MM', wake?: 'HH:MM', hours?: n}, habits?: [{name, done?: bool, value?: n, skip?: bool}], question?: string }
  ```

- **Код раскладывает ответ агента по разделам:**
  - еда — как сейчас;
  - вес — upsert `WeightEntry`, логику вынести из `routes/nutrition.ts` в сервис;
  - сон — запись в привычку сна из `NutritionGoal.sleepHabitId` с отбоем и подъёмом;
  - привычки — сопоставление по нормализованному имени, при неоднозначности кнопки выбора; запись через `setHabitEntry`;
  - вопрос — код собирает факты (сегодня/неделя/тренд/фаза/серии из `computePlan` и `habitStats`), Hermes формулирует ответ; если Hermes недоступен — шаблон.
- **Undo:** один «↩️ Отменить» откатывает всё, что записало сообщение (расширить механизм `tlu:` jobs: хранить список записей всех типов).
- **Без Hermes** (офлайн): простые шаблоны регулярками — «вес 70.5», «спал 7», «лёг 1:30 встал 8» — пишутся без агента; остальное → понятное «агент недоступен».

## Этап 3. Утренний и вечерний брифинг
Вместо отдельных сообщений (утро сон/вес, вечер сводка привычек, 21:00 тренировка, 22:00 «всё записал?») — **два сообщения**:
- **Утро** (`morningCheckinTime`, по умолчанию 09:00):
  - вчера: ккал/белок к плану, привычки X/Y;
  - сегодня: план ккал/белка (фаза, тренировочный день), утренние привычки;
  - кнопки: вес −0,5 / как вчера / +0,5; сон — пресеты отбоя и подъёма.
- **Вечер** (`checkinTime`):
  - осталось ккал/белка и 1–2 варианта добрать белок из любимых продуктов (логику `utils/suggest.ts` перенести на сервер упрощённо: топ по белку на ккал);
  - кнопки привычек (как сейчас), «тренировка была?» — если тренировочная привычка не отмечена;
  - «день записан полностью».
- **Технически:** `services/briefing.ts` собирает оба сообщения из pure-функций (тестируемо, как `buildCheckinMessage`). Существующие обработчики кнопок (`ci:`/`cd:`, `sl:`/`wt:`/`tr:`/`dc:`) переиспользуются. Отдельные кроны утренних вопросов, тренировки и «всё записал?» в `prompts.ts` отключаются.
